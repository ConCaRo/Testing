注意事項

LINEのサブプロフィール機能（以下「本サービス」）はLYPプレミアム会員を対象に提供します。ユーザーは以下の事項に同意しない限り、本サービスを利用することはできません。

 

  1. 本サービスの悪用（詐欺、なりすましなど）について他のユーザーからの報告などにより、懲戒を受ける場合、LINEアカウントの利用が制限されます。
  2. メインプロフィール / サブプロフィールについて
    1. メインプロフィールとは、LINEアカウントの作成によってユーザーが設定可能な「既存の」プロフィール情報（画像、表示名など）です。サブプロフィールとは、お客様以外の第三者に対して表示設定が可能な、「本サービスを使って新しく作成した」プロフィール情報（画像、表示名など）です。
    2. メインプロフィール、サブプロフィール（過去に設定していたサブプロフィールを含みます。）、それらの関連性およびお客様の特定の友だちへのプロフィールの設定状況といった本サービスに関連する情報は、公開情報としてお客様以外の第三者が閲覧可能になります。特定のユーザーに対し、お客様が設定したメインプロフィール / サブプロフィールのみを表示することはできませんので、その点について十分ご理解とご認識の上、ご利用ください。
    3. サブプロフィールは、LINEの友だち関係を活用するサービスなど（当社サービスに限りません。）で利用可能です。利用可能サービスの詳細は「3.サブプロフィール利用可能サービスの詳細」をご覧ください。
    4. お客様がサブプロフィールを設定している他のユーザーにもお客様のメインプロフィールに関する情報が表示される可能性があります。
    5. お客様がサブプロフィールを設定していない他のユーザーにも、お客様のサブプロフィール（過去に設定していたサブプロフィールを含みます。）に関する情報が表示される可能性があります。
  3. サブプロフィール利用可能サービスの詳細
    1. 利用可能サービス例
      1. LINE友だちに限って、設定したメインプロフィール / サブプロフィールが友だちに表示されます。
      2. トーク内のメンバーに設定したメインプロフィール / サブプロフィールが表示されます。
      3. ブロック/非表示をした友だちには、ブロック/非表示する前に設定したメインプロフィール / サブプロフィールが表示されます。
      4. お客様のLINEアカウントをお気に入りに追加した友だちにサブプロフィールを設定した場合、友だちにプロフィールを更新したことが通知されます。
      5. LINE VOOMでは、投稿者名、ソーシャルプロフィール、コメントで、設定されたメインプロフィール / サブプロフィールが表示されます。
      6. 1:1通話、グループ通話中には設定されたメインプロフィール / サブプロフィールが表示されます。
      7. LINEギフトを利用する過程で設定されたメインプロフィール / サブプロフィールを確認することができます。 (贈り先選択、もらったギフト、贈ったギフト、誕生日カレンダーなど）
      8. LINEスタンプ、絵文字、着せかえを使用する過程で設定されたメインプロフィール / サブプロフィールを確認することができます。 (友だち選択リスト、受けとったプレゼントリストなど)
      9. トーク内の投票、イベント、あみだくじ機能では設定されたメインプロフィール / サブプロフィールが表示されます。
    2. 主な注意点
      1. ブラウザーを使って、LINE VOOMなど、LINEのファミリーサービス（LINEアカウントで利用可能なメッセンジャー以外のサービス。以下同じ。）を利用する際、ログインしていない場合はサブプロフィールが利用できません。
      2. LINEの友だち関係を活用しないLINEのファミリーサービスでは、サブプロフィールが利用できません。
      3. トーク内のプロフィールが表示される各種メッセージ（例えば、レストランの予約確定メッセージのように企業のLINE公式アカウントから配信されるメッセージ、友人がLINE GAMEのスコアをトーク内に共有すると表示されるメッセージなど）には、設定変更前のメインプロフィール / サブプロフィールなど、お客様が友だちに設定中のプロフィールと異なるプロフィールに関する情報がその友だちに表示されることがあります。
      4. LINE公式アカウントとのやりとりにはメインプロフィールが利用されます。
      5. グループ内でのトーク等を通じて、LINE公式アカウントがサブプロフィールの情報を取得 / 保存する可能性があります。
      6. LINE公式アカウント運営者や連動アプリ（LINEでログインまたは権限を許可してLINEアカウントと連携したサービスを指します。以下同じ。）のサービス提供者に提供されたサブプロフィールは、ユーザーが解約などによりLYPプレミアム会員の資格を失っても、メインプロフィールとともに当該運営者や当該サービス提供者が引き続き保持し続けることがあります。
      7. グループ内でのトークにLINE公式アカウントが含まれる場合、LINE公式アカウントがメインプロフィールが設定されているユーザーに向けてサブプロフィール名で発話・応答、またはサブプロフィールが設定されているユーザーに向けてメインプロフィール名で発話・応答する可能性があります。
      8. 連動アプリにお客様のプロフィール情報権限を付与した場合は、サービス提供者にメインプロフィールが提供されます。
      9. 連動アプリが友だちやグループ情報を求めている場合、サブプロフィールを設定したお客様の友だちが当該アプリを利用した際、お客様の同意なく、お客様のサブプロフィールがサービス提供者に提供されます。これは 「LINEアプリの設定画面 > プライバシー管理 > アプリからの情報アクセス」において制御をすることができます。
      10. 連動アプリが友だちやグループ情報を求めている場合、サービス提供者は、お客様のメインプロフィールとサブプロフィールを同時に把握し、どの友だちにどのプロフィールを表示しているのかといった関係性を把握する可能性があります。
      11. サブプロフィールを設定した相手がLINEアプリの特定のバージョン以下を使用している場合や、グループ名を設定せず、「友だちをグループに自動で追加しない」を設定したグループトークの場合、グループ名にメインプロフィール名が表示される場合があります。
      12. LINE VOOM LIVE、トーク内の日程調整機能ではメインプロフィール名が表示されます。
      13. LINE VOOM投稿のリンクを外部SNSに共有する場合、投稿者のメインプロフィールが表示されます。
      14. LINE VOOM投稿（メンションやコメントも含む）やそのリンクをトーク内に共有する場合、送信者に見えるプロフィール名がそのまま表示されます。そのため、LINE VOOM投稿者とトーク内のメンバー間のサブプロフィール設定状況が識別される可能性があります。
      15. 相手がお客様を友だちに追加していない場合は、LINE VOOMの公開リストにメインプロフィールが表示されることがあります。
      16. メンションを含むノート、ノートのコメントをコピーしてトーク内に貼り付ける場合、送信者に見えるプロフィール名がそのまま貼り付けられます。その際、トーク内のメンバーそれぞれに設定したメインプロフィール / サブプロフィールの設定状況が識別される可能性があります。
      17. ノートの本文にメンションするとトーク内に表示されるメッセージ形式の通知に、作成者に見えるプロフィール名がそのまま表示されます。その際、トーク内のメンバーそれぞれに設定したメイ
        ンプロフィール / サブプロフィールの設定状況が識別される可能性があります。
      18. 一度送信された通知（ノートの作成通知など）に表示されるお客様のプロフィールの名前は、変更したとしても通知には適用されません。
      19. 友だち追加時に相手に通知される場合に、メインプロフィールで通知されます。
      20. Chrome版のLINEでお客様を言及したメッセージが別のチャットルームで共有される場合は、共有メッセージに変更前のプロフィール名が表示されることがあります。
      21. プレミアムバックアップを​ご利用​中にメディア破損などの​理由で​バックアップが​失敗した​場合、​公式アカウントから​「バックアップ失敗に​関する​メッセージ」が​送信されます。​この​メッセージでは、​プロフィールの​切り​替え状況などに​よっては、実際の設定と異なる送信者名（メインプロフィール / サブプロフィールのどちらかの表示名）が​表示される​ことがあります。
  4. LYPプレミアム会員に対するサービス範囲
    1. LYPプレミアム会員を対象にメインプロフィールの他、サブプロフィールが最大2つまで作成することが可能となります。
    2. LYPプレミアム会員期間中はサブプロフィールのすべての機能を使用することができます。
    3. LYPプレミアムを解約した場合であっても解約日から30日間の猶予期間が与えられ、その期間中は本サービスを利用することができます。猶予期間中にLYPプレミアムに再度会員登録する場合、サブプロフィールはそのまま維持されますが、再度会員登録をせずに猶予期間が終了すると、当社が保存するサブプロフィールが削除され、サブプロフィールが設定された友だちにはメインプロフィールが表示されるようになります。
    4. 一度削除されたサブプロフィールは復元できません。
    5. 本注意事項に同意の上本サービスを利用開始いただいたユーザーが、LYPプレミアムが解約された後に本サービスのご利用を再開した場合にも、引き続き本注意事項への同意は継続しているものとして取り扱います。
  5. LYPプレミアム会員がLINEアカウントの電話番号をサブプロフィールの適用対象外の国に変更する場合 
    1. LYPプレミアム会員はLINEアカウントに登録している電話番号を日本の電話番号以外（海外）の電話番号に変更することができます。サブプロフィール適用対象外の国の電話番号が登録されたアカウントでログインした場合、LYPプレミアムが満了した状態となり、猶予期間が30日提供されます。(適用対象外の国でのログイン日時基準、30日間提供)
    2. 猶予期間内にアカウントに登録した電話番号を適用対象国に変更しなかった場合、LYPプレミアム会員の資格が取り消され、当社が保存するサブプロフィールが削除されます。（サブプロフィールの編集や友だち設定はできません）
    3. 猶予期間内にアカウントに登録した電話番号を適用対象国に復旧する場合、サブプロフィールはそのまま保存されます。
    4. アカウントに登録した電話番号を適用対象国に変更する場合、サブプロフィールは移行されます。
